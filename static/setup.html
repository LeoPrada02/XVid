Connect your phone to XVid

Two quick steps, only once. Keep this page open.

This page needs a pairing code. On the PC, open XVid, tap Add a phone, and scan the QR code.

  1. 1. Trust your PC

    Your phone needs XVid's certificate so it can talk to your PC securely.

    Download certificate

    Then install it:

    1. Open Settings and search for CA certificate. (Usually Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate.)
    2. Tap Install anyway and pick xvid-ca.crt from Downloads.
    3. Come back to this page.

    Waiting for the certificate…

  2. 2. Open XVid

    Logs you in automatically. Then install it so it shows up in X's Share menu.

    Open XVid
